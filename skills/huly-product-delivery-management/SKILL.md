# 产品交付综合总览

## 使用范围

本 Skill 可直接处理用户提供的会议纪要、计划、任务状态、测试报告、发布记录、指标和复盘资料，不要求其他 Skill 先行处理。根据资料与用户目标选择最小必要范围：单项状态摘要、项目周报、综合健康度或跨阶段交付总览。

其他工具或 Skill 产生的结果可以作为普通输入，但仅为可选资料来源，不自动调用、不移交任务，也不因其缺失而停止工作。

## 综合输出

合并为一张表，避免重复七个模块：

| 区域 | 内容 |
|---|---|
| 总体状态 | 当前阶段、健康度、结论和证据时间 |
| 本期进展 | 已完成且可验证的交付物 |
| 决策 | 新决定、待决定、冲突及 Owner |
| 计划偏差 | 里程碑、关键路径和影响 |
| 质量与发布 | 测试、残余风险和发布准备状态 |
| 数据 | 已观察指标、口径和限制 |
| 风险与阻塞 | 严重度、Owner 和解除条件 |
| 下一步 | 行动、Owner、时间和完成定义 |

总体健康度只能是 `ON_TRACK / AT_RISK / OFF_TRACK / UNKNOWN`，并给出证据。资料不足时明确未知项，不补造进度、估算、质量结论或因果关系。

只有用户明确授权且目标系统可用时才写回；不替代研发、QA 或运维执行。
