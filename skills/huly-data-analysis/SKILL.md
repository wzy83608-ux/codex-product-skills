# 产品数据分析

## 分析前提

先明确产品问题、指标定义、计算口径、时间范围、比较基线、分群、数据来源、新鲜度和缺失情况。口径或数据不足时先输出缺口。

## 证据规则

- 区分观察到的事实、相关性、合理推测和因果结论。
- 没有实验、自然实验或可靠识别策略时，不得声称某项改动导致指标变化。
- 不补造基线、目标值、样本量、统计显著性或用户反馈。
- 同时寻找反证、替代解释、数据质量问题和选择偏差。
- 如果上游决定使用 `METRIC_WAIVED`，保留该决定、原因和适用范围。

## 输出

输出指标口径表、关键变化、分群差异、可能解释、反证、业务影响、数据限制、结论可信度和建议决策。建议应明确是继续观察、补数据、做实验、扩大、调整还是停止。

未获明确授权时不修改数据源、看板或 Huly。
