# 项目进度监控

## 状态口径

只使用 `NOT_STARTED / IN_PROGRESS / BLOCKED / AT_RISK / DONE / UNKNOWN`。状态必须关联证据和证据时间；计划日期不等于实际完成。

## 分析方法

- 读取计划里程碑、可验证产物、当前 Gate、Issue 状态、依赖和最新进展证据。
- 对比计划与实际，识别偏差、阻塞持续时间、关键路径影响和下一个里程碑。
- `DONE` 必须有完成产物或责任 Owner 的有效确认。
- 只有工作已拆分且权重规则明确时才使用百分比；否则用阶段、状态和交付物表达。
- 对阻塞给出 Owner、解除条件、目标时间、恢复方案和需要升级的决策。

## 输出

先输出进度表：工作项、计划状态、实际状态、证据、偏差、Owner、阻塞和下一步。随后给出总体健康度 `ON_TRACK / AT_RISK / OFF_TRACK / UNKNOWN` 及依据。

未获明确授权时只读取和汇总，不修改任务状态。
