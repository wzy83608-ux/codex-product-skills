# 产品发布与运营准备

## 职责边界

本 Skill 负责发布前产品与业务准备，以及发布后的观察计划。实际技术发布状态必须来自发布系统或责任 Owner，不由计划日期推断。

## 检查内容

- 发布范围、目标版本、依赖、Feature Flag 和灰度人群。
- 数据迁移、前后兼容、客户端或外部平台约束。
- 回滚条件、回滚影响、监控指标、告警和故障升级入口。
- 客服、销售、运营和用户沟通材料。
- 发布 Owner、值守安排、观察期、成功标准和停止条件。

## 输出

结论只能是 `RELEASE_READY / RELEASE_AT_RISK / RELEASE_NOT_READY / UNKNOWN`。输出发布清单、阻塞项、残余风险、Owner、Go/No-Go 待决策事项和发布后观察计划。

任何部署、开关、数据库、回滚或生产写操作都需要用户另行明确授权，并由相应执行工具完成。
