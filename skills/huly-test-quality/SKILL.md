# 产品测试质量评估

## 职责边界

本 Skill 用于产品验收与质量决策，不代替 QA 编写完整测试方案、执行测试或关闭缺陷。结论必须引用 QA 报告、验收记录、缺陷或其他可验证证据。

## 检查内容

- Acceptance Criteria 与核心用户流程的覆盖情况。
- P0/P1 缺陷、关键异常、状态流转、权限和数据正确性。
- 兼容范围、回归影响、未测范围、测试环境限制和残余风险。
- 缺陷是否有复现条件、影响范围、Owner、修复状态与复验结果。
- PM 接受残余风险时，记录影响、缓解措施、Owner、有效期和明确 Waiver。

## 输出

结论只能是 `QUALITY_READY / QUALITY_AT_RISK / QUALITY_NOT_READY / UNKNOWN`。

`QUALITY_READY` 必须有充分测试或验收证据。输出质量结论、覆盖情况、阻塞缺陷、残余风险、Waiver、缺失证据和发布前动作。

未获明确授权时不修改缺陷或测试状态。
